# Karya Kreatif Proyek SIK - RSU Permata Bekasi

Folder ini berisi dua karya kreatif pendukung implementasi sistem:

1. **Infografis Alur Pelaporan Berkas Terlambat (CR-1)**: Visualisasi langkah-langkah bagi kepala unit dalam memantau dan mengevaluasi daftar rekam medis mingguan yang belum dikembalikan.
2. **Poster Sosialisasi Kepatuhan Pengembalian Rekam Medis**: Desain materi edukasi dan pengingat bagi petugas ruangan/tenaga medis agar mengembalikan berkas rekam medis tepat waktu demi kelancaran mutu pelayanan.
